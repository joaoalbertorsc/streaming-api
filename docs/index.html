Streaming API

Uma API REST que simula um serviço de streaming: um login por conta, perfis com faixa etária, planos que limitam perfis e catálogo, um PIN para conteúdo adulto, histórico de visualização e avaliações. Feita em TDD, do enum ao teste de ponta a ponta.

Arquitetura

Do token ao banco, em seis passos

Toda requisição autenticada percorre o mesmo caminho. Cada camada tem uma responsabilidade só, e as regras de negócio vivem em classes pequenas que podem ser testadas sem subir o Spring.

03:00

TrashPurgeJob roda todo dia e apaga de vez os perfis que estão há mais de 30 dias na lixeira, junto com histórico e avaliações.

Modelo de domínio

Uma conta, vários perfis, um histórico por perfil

A conta é o único login. Os perfis vivem dentro dela, e cada visualização gera uma linha nova de histórico, por isso assistir duas vezes aparece duas vezes. Passe o mouse sobre uma entidade para ver só as relações dela.
